# 📷 材集カメラ (ZaishuCamera)

フィールドワーク・材料選定（材集）用の**高速メモ付きカメラ Androidアプリ**です。
「撮影 → ゼロタップでメモ入力 → 下部白余白へ日時・フォルダ名・チェック印・テキスト合成＆GPS位置情報（EXIF）保存 → 即座に次の撮影へ復帰」を単一画面（Single Screen）で完結させます。

## ✨ 主な特徴
1. **起動0秒でカメラプレビュー**（スプラッシュ画面・メニュー画面なし）
2. **ワンタップ「✓ チェック（仮決め）」ボタン**：
   - 現場で仮決めした材料を、撮影前後どちらでもボタン1つでチェックON/OFF可能。下部白余白の右側に視認性の高い緑の「✓」チェックマークが合成印字されます。
3. **案件・場所フォルダ分け＆GPS位置情報（EXIF）同時保存**：
   - 端末内の専用フォルダ（`DCIM/ZaishuMemo/<フォルダ名>`）および `DCIM/Camera` に高品質JPEG（95%）として保存し、EXIFに撮影日時とGPS座標を記録します。
4. **現場仕様の操作性**：
   - 本体音量ボタン（＋／ー）でのシャッター撮影、ワンタップ倍率切替（0.5x / 1x / 2x）＆ピンチズーム、常時点灯ライト（トーチ）、シャッター触覚フィードバックを搭載。
