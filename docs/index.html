プライバシーポリシー（材集カメラ / ZaishuCamera）

本プライバシーポリシーは、スマートフォン向けアプリケーション「材集カメラ」（以下「本アプリ」）における利用者情報の取り扱いについて定めるものです。

1. 取得する権限と利用目的

  • カメラ権限（android.permission.CAMERA）：写真の撮影およびライト（トーチ）機能の制御のためにのみ使用します。
  • 位置情報権限（ACCESS_FINE_LOCATION / ACCESS_COARSE_LOCATION）：撮影した写真ファイル（JPEG）のEXIFメタデータに撮影場所のGPS座標を記録するためにのみ使用します。
  • アプリ内購入（com.android.vending.BILLING）：Google Play ストアを通じたPro永久ライセンス（買い切り）の購入および購入状態の復元のためにのみ使用します。

2. データの保存先および外部送信について

本アプリで撮影した写真、入力した案件フォルダ名・メモテキスト、および取得したGPS位置情報は、すべてお使いのスマートフォン端末内（内部ストレージ／カメラロール）にのみ保存されます。開発者のサーバーや第三者の外部サーバーへ写真や位置情報が送信・収集されることは一切ありません。

3. 第三者提供および広告配信について

本アプリには第三者広告配信SDKや行動追跡（トラッキング）ツールは一切組み込まれておらず、利用者の個人情報を第三者へ提供することはありません。

4. お問い合わせ・改定

本ポリシーに関するお問い合わせは、Google Play ストア内の本アプリ掲載ページに記載の開発者連絡先までお願いいたします。
